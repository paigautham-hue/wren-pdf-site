# Report a problem or an inappropriate answer

Wren PDF never sends anything by itself. To report a problem with the app, or an answer or summary written by its optional model that is inappropriate or wrong, send the report yourself in one of these ways.

**Reports made here are public.** Do not include confidential text from your documents. In the app, "Report this answer" shows exactly what the report contains before you copy it, and leaves the document's passages out unless you choose to include them.

- [Report an inappropriate or wrong written answer](https://github.com/paigautham-hue/wren-pdf-site/issues/new?template=answer.yml)
- [Report another problem](https://github.com/paigautham-hue/wren-pdf-site/issues/new?template=problem.yml)

If you would rather not post publicly, use the support contact shown on the app's Microsoft Store page.

Every report is read. An answer that is reported as inappropriate is reviewed, and where the app can be changed to prevent it (for example by tightening the checks an answer must pass, or changing the model), that change is made in a later version.
